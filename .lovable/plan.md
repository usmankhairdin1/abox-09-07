# Phase 52 / Batch B1 — `B1 is not defined` Runtime Fix

Minimum correction only. No redesign, no scope change, no ABox application change.

## A. Exact root cause

`tools/figma-plugin/plugin.js:497`, inside `b1Collections()`:

```js
return B1.collections.map((spec) => {
```

The generated data object produced by `extract-b1.mjs` and emitted into
`tokens-b1.js` is named **`ABOX_B1`**. Every other B1 call site uses the correct
identifier (`ABOX_B1.primitives`, `ABOX_B1.semantics`, `ABOX_B1.tones`,
`ABOX_B1.metalAliases`, `ABOX_B1.spacing`, `ABOX_B1.radius`, `ABOX_B1.border`,
`ABOX_B1.layout`, `ABOX_B1.control`, `ABOX_B1.shadows`, `ABOX_B1.collections`).
This single site omits the `ABOX_` prefix.

Classification: **naming mismatch — a bare undefined identifier reference.**
Not a module-loading failure, not a build failure, not a data problem.
`tokens-b1.js` is concatenated correctly by `build.mjs` (confirmed: `code.js:91`
contains `const ABOX_B1 = {`).

Why it fails immediately: `b1Collections()` is the first function both
`Create foundation variables` and `Verify foundation variables` call, so the
`ReferenceError: B1 is not defined` is thrown before any collection or variable
is touched. This also explains why no variables were created and no validation
ran. The same defect exists at the mirrored generated line `code.js:2272`.

## B. Minimum code correction

Exactly one token changed, in the source file only:

- `tools/figma-plugin/plugin.js:497`
  - from: `return B1.collections.map((spec) => {`
  - to:   `return ABOX_B1.collections.map((spec) => {`

No other line in `plugin.js`, `tokens.js`, `tokens-b1.js`, `extract-b1.mjs`,
`build.mjs`, `manifest.json` or `ui.html` changes.

## C. Generated-file / build impact

- `code.js` is regenerated by running `node tools/figma-plugin/build.mjs`.
- `code.js` is never hand-edited. The regenerated file will differ from the
  current one only at the mirrored line (`B1.collections` → `ABOX_B1.collections`).
- Post-build assertion: `grep -n "[^_A-Z]B1\." code.js` must return no matches
  other than the two prose strings `"…do not proceed to B1."`.

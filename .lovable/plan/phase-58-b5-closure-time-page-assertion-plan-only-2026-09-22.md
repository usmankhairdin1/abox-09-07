# Phase 58 — B5 closure-time page assertion (PLAN ONLY)

## Exact source location of the failing assertion

`tools/figma-plugin/plugin.js`, inside `verifyB5()` (starts at line 2566).

The failing block is lines **2721–2745**:

- 2723 `const writable = [B4_PAGE, "02 Patterns", "03 Shells"];`
- 2724 `const b5PageEvidence = [];`
- 2725–2734 loop: skip any page in `writable`; for `06 Documentation` skip only when it is empty or exactly `b10ApprovedNames()`; for every other page push **every** top-level child into the evidence array, with `if (b5PageEvidence.length >= 40) break;`

Everything above line 2721 (variant inventory, property definitions, slot-capability check, B1/B2/B3 preservation at 2700–2714) and the B0 seven-page/order assertion at 2715–2720 are unrelated and pass.

## Why it reports 40 unexpected nodes

This is the same class of stale batch-local assertion already corrected for B0 and B4: it was written when B5 ran against a file where only `01 Components`, `02 Patterns` and `03 Shells` existed as populated pages. It hard-codes those three as the only allowed populated pages and gives no allowance at all for `04 Experiences` (B8) or `05 Screens` (B9).

At closure time those pages legitimately hold 5 + 179 = 184 approved frames. The loop begins pushing them all, and the `>= 40` guard inside the inner `for` caps the array. So **40 is the evidence-buffer cap, not a real count of offending nodes** — every one of the 40 listed lines is an approved B8 experience frame. `06 Documentation` passes its special case, `00 Foundations` is empty, so the 40 come entirely from `04 Experiences` (all 5) and `05 Screens` (the first 35 reached before the cap).

## Exact minimal correction

Replace only lines 2721–2745 with an allowlist check built from the canonical helper `aboxApprovedPageTopLevel()` (plugin.js 547), the same source B0 and B4 already use — no new inventory source, no generic allowance:

- Drop `writable`, the `06 Documentation` special case, and `b10ApprovedNames()` use in this block.
- For **every** page, look up its approved top-level name map and record any top-level child not in it as `page › name (type) id=…`.
- Because the helper maps `01 Components` to `ABOX_B4.sets` + `ABOX_B4.components`, `02 Patterns` to B6, `03 Shells` to B7, `04 Experiences` to B8, `05 Screens` to B9, `06 Documentation` to B10, and `00 Foundations` to an empty list, all seven pages become checked rather than three being skipped outright.
- Keep a total counter separate from the 40-line evidence cap so the label prints the true number of offenders, not the buffer size.
- New label: `each page holds only its approved B0–B10 top-level inventory (00 Foundations must stay empty); unexpected nodes: <n>`.
- The `B5 PAGE EVIDENCE` printing block at 2741–2745 stays, fed by the same array.

No other line in `verifyB5()` changes. All B5 variant, property, binding, count, slot-capability and limitation checks stay byte-identical, as do the B1/B2/B3 preservation checks and the B0 page-order assertion.

# Phase 59 — Fix duplicate current-app identity (PLAN ONLY)

## Exact root cause

The preflight did its job: it stopped before any Figma mutation. The collision is **not** a duplicate key — it is a duplicate **frame name**.

Verified offline against the generated manifest (`tools/figma-plugin/tokens-current-app.js`):

- 179 screens, 12 groups, **zero duplicate `key` values**.
- **Two duplicate `name` values**, covering 5 screens:

```text
ABox/CurrentApp/Agency Operations/SCR-AGENCY-SETUP   x2
  current:route:/app/agency            (/app/agency/,          id SCR_AGENCY_SETUP)
  current:route:/app/agency/entities   (/app/agency/entities,  id SCR_AGENCY_SETUP)

ABox/CurrentApp/Public & Marketplace/UX-009          x3
  current:route:/plans                 (/plans/,               id UX-009)
  current:state:plans:filters          (/plans#filters,        id UX-009)
  current:state:plans:edit-quote       (/plans#edit-quote,     id UX-009)
```

The preflight loop in `plugin.js` (`currentAppPreflight`) tests `keys[screen.key] || names[screen.name]` and reports `screen.key` in the message. The offender was a *name* clash, so the reported key `current:route:/app/agency/entities` looked misleadingly like a duplicate route.

The extractor builds the name as:

```js
name: "ABox/CurrentApp/" + moduleLabels[module] + "/" + slug(screen.id || screen.route || screen.title)
```

`screen.id` is the **governed screen ID from B9** (`SCR_AGENCY_SETUP`, `UX-009`). Governed IDs are legitimately shared by several routes and by route-plus-state variants, so preferring `id` over the route collapses distinct screens onto one name. This is an extractor naming bug, not a B8/B9 join fault, not a duplicate route record, and not an inventory error: route declarations, module assignment, governed-host expansion and state expansion are all correct and unique at key level.

## The fix — deterministic unique naming rule

Derive the name from the already-unique stable key, keeping the governed ID as a readable qualifier:

```text
ABox/CurrentApp/<Module Label>/<governed-id-slug>/<identity-slug>
```

where `identity-slug = slug(screen.key without the "current:" prefix)`, and the governed-id segment is omitted when B9 supplies no `id`.

Resulting names for the failing cases:

```text
ABox/CurrentApp/Agency Operations/SCR-AGENCY-SETUP/route-app-agency
ABox/CurrentApp/Agency Operations/SCR-AGENCY-SETUP/route-app-agency-entities
ABox/CurrentApp/Public & Marketplace/UX-009/route-plans
ABox/CurrentApp/Public & Marketplace/UX-009/state-plans-filters
ABox/CurrentApp/Public & Marketplace/UX-009/state-plans-edit-quote
```

Because the key is already proven unique across all 179 screens, the name is unique by construction and fully deterministic. No screen is dropped, no route is invented, no identity is weakened, and mobile companions keep deriving their names from the (now unique) desktop name.

## Files and functions to change

1. `tools/figma-plugin/extract-current-app.mjs`
   - Screen spec builder: replace the `name:` expression with the rule above.
   - Add a hard offline assertion **before** writing the manifest: zero duplicate `key`, zero duplicate `name`, zero duplicate desktop/mobile frame name across the whole manifest; on violation, throw with every colliding value listed. This runs at generation time, so a bad manifest can never reach Figma.
   - Add an explicit regression assertion naming the five previously colliding keys and asserting their names are pairwise distinct while `screens.length === 179`.
2. `tools/figma-plugin/tokens-current-app.js` — regenerated by running the extractor (generated file, not hand-edited).
3. `tools/figma-plugin/plugin.js`
   - `currentAppPreflight`: keep the duplicate check (not weakened), but report *which* dimension collided (`key` vs `name`) and both offending screen keys, so a future failure is self-diagnosing. Detection strictness is unchanged.
   - No change to `currentAppAssertProtected`, `currentAppGuarded`, rollback, placement, or idempotency logic.
4. `tools/figma-plugin/code.js` — rebuilt bundle via `node build.mjs`.
5. `roadmap.md` / `tools/figma-plugin/README.md` — one-line note on the naming rule.
